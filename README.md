# Eftba

Eftba - Epic Fantasy Text-Based Adventure

======

Welcome to EFTBA (the Epic Fantasy Text-Based Adventure).

This is my first personal programming project for Boot.dev!

======

If you want to play this game with full-emoji support (recommended) 😁
then I recommend running it with Windows Terminal! (Available from the Microsoft Store)

Then run the windows terminal. Navigate to your Eftba installation.
(cd Documents\Eftba)

Then run the Eftba.exe with windows terminal like this.
( .\Eftba.exe )

======

You can manually quit at any time with Ctrl + C !

You can also 'save' the game anywhere in the Overworld by typing 'save'

======

Many commands also work with their abbreviated one letter version!

Such as using 'n' 'e' 's' 'w' instead of North, East, South or West respectively.

Except for commands like Enter, or Save. Because their abbreviated version would conflict with movement commands.

Potions in this game when used in combat are used in priority of Strongest to Weakest.

Holy Elixir <- health potion <- murky potion <- small red potion

Many choices in this game are not case-sensitive. However using an item is case-sensitive!

If you start typing (or bump a key) while the game is printing you might accidentally enter a weird command.

That can result in a wasted turn.

To prevent that you can always zero out your input with [Backspace] to make sure your command is entered cleanly!
